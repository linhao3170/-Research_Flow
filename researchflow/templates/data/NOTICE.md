# Bundled T0 dataset provenance

`synthetic_breast_cancer.csv` is generated by `scripts/build_template_dataset.py`
from a fixed NumPy seed (`20261114`). It contains **no third-party rows** and no
real patient data: all identifiers, timestamps and measurements are synthetic.

- License: **CC0-1.0** (the project dedicates this generated data to the public domain).
- Regeneration: `& .venv\Scripts\python.exe scripts/build_template_dataset.py`
  produces byte-identical content and the same `sha256` recorded in
  `registry.json`.
- Columns: `patient_id` (group), `event_time` (time order), `age`, `bmi`,
  `f1`–`f6` (numeric features), `diagnosis` (binary target).
- Offline: the file ships with the repository; no download or network access is
  required at run time.
