# ResearchFlow Testing and Benchmark

## 1. 适用条件 / When to use

在以下情况使用：

- 编写或评审单元、集成、契约、端到端、权限、负例、故障注入、离线复核测试。
- 运行 T0/T1/T2 验收，准备 G0–G7 门禁证据。
- 构建 RF-Bench 用例、运行基准、分析统计结果。
- 判断某项结果能否写成“已实测/已验证”，或只能写“计划/未测”。

不用于：修改测试预期来掩盖错误；把开发调试集混入盲测；用重复运行冒充独立样本。

## 2. 输入与前置检查

1. 已确认测试对象、验收条件、证据等级和门禁要求。
2. 已确认解释器：Python 3.11.16（64 位）绝对路径；不得用 PATH 默认解释器。
3. 已确认测试数据来源、是否合成、是否脱敏、是否允许留存。
4. 已确认测试命令、工作目录、超时、资源限制、日志路径。
5. 已确认正式实验是否需要预注册；若需要，检查预注册文件是否已冻结。
6. 已确认本次是开发测试、验收测试还是盲测；三者不得混用。

若测试目标或验收条件不明确，先补规格；不得先跑再解释。

## 3. 执行步骤

1. **分层测试计划**：单元 → 集成 → 契约 → 端到端 → 权限/负例 → 故障注入 → 离线复核。
2. **每个核心模块写正例和负例**：至少覆盖合法路径、非法输入、边界、权限拒绝、失败恢复。
3. **准备测试数据**：合成/公开优先；固定种子；记录数据版本与哈希；敏感数据脱敏。
4. **运行测试**：使用真实命令，记录解释器、工作目录、开始/结束时间、退出码、测试总数、失败数、日志路径。
5. **保存原始输出**：stdout/stderr、JUnit/JSON 报告（如有）、失败复现命令；不只保存摘要。
6. **判定结果**：区分设计目标、计划值、实测值、未测值；不得把计划值写成实测。
7. **统计比例指标**：报告分子、分母、区间、任务级统计；不得只报百分比。
8. **独立性检查**：同一任务的重复运行不能当成独立统计样本；盲测集不得混入开发调试集。
9. **预注册检查**：正式实验前冻结任务、故障、规则、种子、等价区间、统计脚本；运行后不得改规则。
10. **门禁映射**：把证据映射到 G0–G7；未满足的门禁保持 `NOT_STARTED`/`IN_PROGRESS`，不得写成 PASS。
11. **失败分析**：定位原因、影响范围、是否阻塞；修复后重跑，不用“重试通过”覆盖失败记录。
12. **更新证据索引**：日志路径、命令、哈希、结论、未测项。

## 4. 不可违反的约束

- 不得通过修改 expected result、测试样本、规则或阈值来掩盖实现错误。
- 不得编造命令、退出码、测试数量、日志或运行时间。
- 不得把未测项写成已测；不得把计划指标写成实测结果。
- 不得把同一任务的重复运行当作独立统计样本。
- 不得把开发调试集混入 G-hold-72 或其他盲测集。
- G-hold-72 属于 T2 独立盲测扩展，不得提前伪造或混入开发调试集。
- 不得在正式实验运行后修改预注册规则、种子或统计脚本。
- 不得用 Agent 自述、截图或摘要替代原始测试输出。
- 不得为了“通过门禁”跳过权限、负例、故障注入或离线复核。

## 5. 输出要求

至少交付：

1. **测试计划**：层次、范围、正反例、数据、环境、命令。
2. **验收矩阵**：验收项 → 测试 → 证据 → 状态。
3. **原始数据索引**：日志、报告、哈希、运行时间、解释器。
4. **统计结果**：分子/分母、区间、任务级统计、样本独立性说明。
5. **失败分析**：失败项、原因、影响、修复/未修复。
6. **未测清单**：明确哪些没测、为什么、何时补。
7. **门禁结论**：只写有证据支撑的状态。

## 6. 验收标准

- 结果可由他人用记录的命令和解释器复算。
- 每个结论都能追溯到原始日志或数据文件。
- 测试总数、失败数、退出码与日志一致。
- 比例指标有分母和区间；重复运行未被当作独立样本。
- 未测项保持未测，没有被文字描述掩盖。
- 负例和权限测试真实执行并有拒绝证据。
- 正式实验的预注册文件与运行记录一致。

## 8. 失败与暂停条件

- 解释器不是 3.11.16（64 位），或测试命令无法复现。
- 测试数据来源/授权/脱敏状态不明。
- 正式实验缺少预注册，或预注册与运行配置不一致。
- 需要修改 expected/阈值才能“通过”。
- 发现盲测集被污染，或重复运行被当成独立样本。
- 关键证据缺失，无法判断门禁状态。
- 测试产生秘密泄漏、越权或系统破坏风险。

暂停时报告：失败命令与退出码、日志路径、已确认/未确认结论、需要用户决定的问题。
