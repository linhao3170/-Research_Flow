## 1. 测试层次

| 层次 | 证明什么 | 典型证据 |
|---|---|---|
| 单元 | 函数/模型行为 | 测试日志、退出码 |
| 集成 | 模块协作 | API/DB/状态机测试日志 |
| 契约 | Schema/API 兼容 | 正/反/边界样例结果 |
| 端到端 | 任务全链 | 运行记录、产物、报告 |
| 权限 | 越权被拒绝 | 拒绝日志/错误码 |
| 负例 | 伪造/缺失/篡改被拒 | 失败断言与 diff |
| 故障注入 | 恢复/超时/崩溃 | 恢复日志、状态审计 |
| 离线复核 | 证据包可独立验证 | 验签输出、信任锚 |

## 3. 状态词汇

- 测试结果：`PASS` / `FAIL` / `BLOCKED` / `NOT_RUN`。
- 证据状态：`NONE` / `PARTIAL` / `COMPLETE`。
- 门禁状态：`NOT_STARTED` / `IN_PROGRESS` / `PASS` / `FAIL` / `BLOCKED`。
- 不得把 `NOT_RUN` 写成 `PASS`；不得把 `PARTIAL` 写成 `COMPLETE`。

## 4. 统计纪律

比例指标必须报告：

- 分子、分母。
- 置信区间或明确的不确定性说明。
- 任务级统计，不只总体百分比。
- 样本独立性说明；同一任务重复运行不得当独立样本。
- 缺失值、排除标准、异常值处理。
