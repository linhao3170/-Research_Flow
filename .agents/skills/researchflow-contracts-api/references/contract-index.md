# 契约索引（草案）

> 重要：截至 2026-11-08，`contracts/` 尚未建立正式 Schema，以下均为**待 G0 冻结**的索引，不是已批准字段表。
> 不得把本文件当作实现合同；字段、枚举、错误码以冻结后的 Schema/OpenAPI 为准。

## 1. 核心实体

| 实体 | 用途 | 主要生产者 | 主要消费者 | 当前状态 |
|---|---|---|---|---|
| `TaskSpec` | 描述任务目标、输入、约束、验收 | 规划/API | StateMachine、Executor、Gate | 待 G0 冻结 |
| `NodeSpec` | 描述 DAG 节点、依赖、模板、资源 | 规划/API | 调度器、Executor | 待 G0 冻结 |
| `EvidenceRecord` | 记录 E0–E3 证据及来源 | Collector | Gate、Verifier、证据包 | 待 G0 冻结 |
| `VerificationReport` | Verifier 的结构化结论 | Verifier | Gate、StateMachine、凭证 | 待 G0 冻结 |
| `CompletionCertificate` | 完成凭证 | Verifier/签发服务 | 外部复核、审计 | 待 G0 冻结 |
| `HarnessEvent` | Harness 工具/轨迹事件 | Adapter/Collector | 证据链、审计 | 待 T2/G7 |
| `DomainPack` | 领域模板、必检项、规则 | 领域包作者 | Gate、Executor、Verifier | 待 G0 冻结 |

## 2. 契约状态

| 状态 | 含义 | 允许的消费者行为 |
|---|---|---|
| `DRAFT` | 内部草稿 | 只能试验，不得依赖 |
| `PROPOSED` | 待评审 | 可写评审意见，不得实现为稳定接口 |
| `FROZEN` | 已批准冻结 | 可按版本实现；改义需新版本 |
| `DEPRECATED` | 弃用中 | 保留兼容期，给出迁移 |

只有用户批准 + 测试通过 + 迁移说明齐全，才可从 `PROPOSED` 进入 `FROZEN`。

## 3. 字段表模板

| 字段 | 类型 | 必填 | 约束/枚举 | 含义 | 来源 | 版本 |
|---|---|---|---|---|---|---|
| `<field>` | `<type>` | 是/否 | `<...>` | `<...>` | `<章节/ADR>` | `<v>` |

要求：

- 每个必填字段有语义和来源。
- 枚举值稳定；扩展枚举必须说明旧消费者行为。
- 时间统一 ISO 8601 带时区；哈希写算法与编码。
- 不定义无来源的“以后可能用”字段。

## 4. API 检查表

- 方法、路径、鉴权、请求/响应 Schema。
- HTTP 状态码与业务错误码分离。
- 幂等键、重复请求行为、超时、重试。
- 分页/过滤/排序的稳定语义。
- 错误响应不泄漏内部路径、SQL、密钥。
- 版本策略：路径版本或媒体类型；弃用周期。

## 5. 兼容性检查

| 变更 | 兼容性 | 必要动作 |
|---|---|---|
| 新增可选字段 | 通常兼容 | 旧消费者忽略；文档更新 |
| 新增必填字段 | 不兼容 | 新版本 + 迁移 |
| 删除字段 | 不兼容 | 弃用周期 + 迁移 |
| 改字段含义 | 不兼容 | 新字段/新版本，禁止静默改义 |
| 扩展枚举 | 视消费者 | 旧消费者需容忍未知值 |
| 改类型/格式 | 不兼容 | 新版本 + 转换 |

## 6. 样例要求

每个契约至少：

1. 合法样例（标注 `synthetic`，不含真实敏感数据）。
2. 非法样例（缺必填、类型错、枚举错、越界）。
3. 边界样例（空、最小、最大、重复、超时）。
4. 预期错误码/校验消息。

## 7. 冻结前检查

- [ ] 字段来源可追溯
- [ ] JSON Schema 与 Pydantic v2 一致
- [ ] 正/反/边界样例通过
- [ ] 错误码稳定
- [ ] 迁移/兼容说明
- [ ] 消费者影响评估
- [ ] 用户批准记录
