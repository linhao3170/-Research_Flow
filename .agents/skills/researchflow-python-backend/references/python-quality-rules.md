# Python 后端质量规则

> 适用：ResearchFlow 后端实现与评审。不是已冻结的开发规范；以 G0 批准的契约和工具链为准。
> 当前仓库状态：未创建 `.venv`、未安装第三方依赖、未锁定依赖版本。

## 1. 解释器

| 项目 | 要求 |
|---|---|
| 版本 | Python 3.11.16（64 位） |
| 绝对路径 | `C:\Users\Administrator\AppData\Roaming\uv\python\cpython-3.11.16-windows-x86_64-none\python.exe` |
| 禁止 | PATH 的 `python`（3.12）、`py -3.11`（32 位 3.11.0） |
| 命令示例 | `& $py -m unittest discover -s tests -v` |

## 2. 依赖

- 使用项目锁定的版本；新增/升级需批准并记录影响。
- 不在运行期 `pip install`，不在测试中临时装包。
- 不引入只为“工程感”的框架或工具。
- 依赖变化时更新锁文件与 `docs/memory/environment.md`（如已批准）。

## 3. 代码规则

| 规则 | 要求 |
|---|---|
| 类型 | 公共函数、API、模型使用类型注解 |
| 输入校验 | 入口校验空值、类型、范围、格式 |
| 异常 | 明确异常类型与错误码；不吞异常 |
| 日志 | 结构化、含关联 ID；不记录秘密 |
| 配置 | 配置与秘密分离；环境注入 |
| SQL | 参数化查询；SQLite WAL；显式事务；迁移版本 |
| 并发 | 遵守并发上限 2；资源上限可配置 |
| 子进程 | 超时、资源限制、独立 cwd、捕获退出码/stderr |
| 网络 | 默认关闭；需要时显式配置 |
| 任意代码 | 不执行用户/Agent 生成的任意代码 |

## 4. 安全

- 秘密只来自正式凭据或环境；不写入 Git、日志、测试、证据包、前端。
- 最小权限：Agent 无状态库/证据/私钥写权限。
- 错误响应不泄漏路径、SQL、堆栈、密钥。
- 敏感数据先脱敏；公开/合成数据优先。
- 子进程不拼接不可信 shell 输入。

## 5. 测试

至少覆盖：

- 单元：纯函数、校验、错误码。
- 边界：空、最小、最大、重复、超时。
- 负例：非法输入、权限拒绝、缺证据。
- 集成：API + 持久化 + 状态机（按已实现范围）。
- 回归：每个修复附复现测试。

测试报告必须含：解释器绝对路径、命令、退出码、测试数、失败数、日志路径、运行时间。

## 6. 检查命令（按项目实际配置启用）

| 检查 | 命令 | 说明 |
|---|---|---|
| 语法/导入 | `& $py -m compileall -q researchflow` | 仅在包存在时 |
| 单测 | `& $py -m unittest discover -s tests -v` | 标准库测试 |
| 类型 | `<项目批准的 mypy/pyright 命令>` | 工具未安装前不声称已跑 |
| 格式 | `<项目批准的 ruff/black 命令>` | 工具未安装前不声称已跑 |
| 安全 | `<项目批准的扫描命令>` | 不把未运行写成通过 |

## 7. 评审检查

- [ ] 结构化日志、无秘密

- [ ] 正例、负例、边界测试
