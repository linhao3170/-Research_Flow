===== TABLE 75 =====
R01: 问题 | 建议回答结构
R02: 你们与 Agent Harness 有什么不同？ | Harness 提供通用运行时；ResearchFlow 是实验领域质量控制层，重点是 E2/E3、L3、证据门控、恢复剪枝与离线凭证。
R03: 哈希链是否能防止所有篡改？ | 不能。它提高篡改可发现性；完全控制主机、密钥和锚定位置的攻击者不在 MVP 威胁模型内。
R04: 为什么还要 L3？ | L1 检查完整，L2 检查自洽；成套伪造可同时通过两者，L3 在新目录从原始数据真实重跑。
R05: 为什么不是所有节点都重跑？ | 成本较高；仅对符合严格 DC 条件的纯节点考虑 SPA，所有剪枝都有证明，无 DC 保守重跑。
R06: DC 是否证明确定性？ | 不是普遍证明，只是限定节点类型、输入、代码、依赖和环境下的经验性资格。
R07: VAS 会不会漏掉高风险项？ | 强制验证集合不可被预算优化排除；VAS 只排序可选验证项，并用同预算实验对比。
R08: 项目是否能在普通电脑运行？ | 首期按单机、16GB、无 GPU、并发 2、内置表格 ML 模板设计；最终以目标设备实测报告为准。
R09: AI 会不会自己编造证据？ | Agent 没有证据库写权限；E2 来自 Collector，E3 来自独立 Verifier，凭证由 Verifier 签名。
